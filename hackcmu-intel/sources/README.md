## What was intentionally not installed

No old `AGENTS.md`, application scaffold, task backlog, human-role assignment, database/PRT contract, dependency lockfile, Git metadata, credentials, or personal ledger history is copied into the receiving project's active configuration. The old BusTime guide and transit-specific diagnostic remain referenced in the case study, rather than becoming default dependencies for an unrelated idea.

The [onboarding snippet](../prompts/AGENTS_SNIPPET.md) and [launch prompt](../prompts/BOOTSTRAP.md) are provided for deliberate use in the receiving repo. Other than reading/copying this intelligence, they do not execute anything automatically.

## Updating a claim

Record the changed fact, source URL or PDF page, observation time, scope, and which decision it affects. Mark superseded claims as historical. Do not silently rewrite a failed experiment as a success, or infer a rule from a recommendation. Recheck current provider documentation before depending on account tiers, pricing, versions, or API availability.
